# 一笔

一个无广告、无账号、离线优先的个人记账 PWA。流水与分类保存在当前设备的 IndexedDB 中。

## 本地开发

```bash
pnpm dev:ledger
```

## 构建

```bash
pnpm build:ledger
```

默认发布路径是 `/pocket-ledger/`。如需部署到其他子路径，可设置 `BASE_PATH`：

```bash
BASE_PATH=/my-ledger/ pnpm build:ledger
```

## iPhone 安装

1. 使用 Safari 打开发布后的地址。
2. 点击分享按钮。
3. 选择“添加到主屏幕”。

首次完整打开后，应用资源会被 Service Worker 缓存。之后可离线使用。流水仅保存在当前浏览器中，清除网站数据或卸载应用前请先在“设置”中导出备份。

发布新构建后，应用会在启动、回到前台以及每小时检查一次更新。新版本下载完成时会显示“发现新版本”，点击“立即更新”后刷新应用；这个过程只替换缓存的应用文件，不会清除 IndexedDB 中的账本。

## 数据导入导出

- Excel：导入兼容随手记标准账本格式，但忽略账户、币种、成员和商家等一笔不使用的字段。导出只包含交易类型、日期、两级分类、金额、事项和备注，可再次无损导回一笔。
- JSON：完整备份一笔中的分类和流水。恢复 JSON 会替换当前设备上的全部账本数据。
